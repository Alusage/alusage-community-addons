# alusage-community-addons

Modules Odoo **génériques d'Alusage**, sous licence **libre** (AGPL-3 / LGPL-3 / GPL-3).
Chaque module déclare sa propre licence dans son `__manifest__.py`.

Regroupe les modules écrits par Nicolas JEUDY / Alusage auparavant éparpillés sur plusieurs dépôts
(Alusage, njeudy, git.myceliandre.fr). Les modules **payants (OPL)** vivent dans `alusage-opl-addons`
(privé) ; les forks tiers ne sont **pas** republiés ici.
