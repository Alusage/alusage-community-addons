# alusage-community-addons

**Tous mes modules Odoo libres, accumulés au fil du temps.** Ce dépôt regroupe les modules génériques écrits par Nicolas JEUDY / Alusage, auparavant éparpillés sur plusieurs dépôts, sous licence **libre** (AGPL-3 / LGPL-3 / GPL-3).

- **Une branche par version Odoo** — chaque module vit sur la branche de sa série.
- Les modules **payants** (licence OPL) sont dans un dépôt privé séparé, `alusage-opl-addons`.
- Chaque module déclare sa propre licence dans son `__manifest__.py`.

```bash
git clone -b 18.0 git@github.com:Alusage/alusage-community-addons.git
```
