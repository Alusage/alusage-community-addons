Choose default top menus on res.users model to be able to have different backends acces, and simplify some backend access.
With this module you can create small simple backend for your customer "jailed" in just one or more apps.

The module also adds an administration screen (Settings > Users & Companies > Top Menus) to create
top menus and build their structure from existing menus. Each menu added this way is either
synchronized with its source menu (same action and views, name, sequence and access groups follow
the source) or duplicated as an independent copy (action and views are copied).
